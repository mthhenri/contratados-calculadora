# contratados-calculadora
Terminal de Agente - Contratados: Aplicação web single-page (HTML/CSS/JS) para gerenciamento, automação de fichas e cálculos mecânicos do sistema de RPG "Contratados", baseado no universo da Fundação SCP (Classe E). Inclui calculadoras de atributos, DTs, regras de descanso e balanceamento para novos personagens.
